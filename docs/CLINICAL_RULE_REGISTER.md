`evidence_source` is a free-text string everywhere. It often names a real
guideline and sometimes a year, which is genuinely useful for a reviewer, but
it is not machine-checkable and carries no URL, no population, no exclusions,
no evidence grade, and no review date.

## What a reviewer must do before any rule is activated

1. For each rule, locate the current primary source and record all ten required
   fields. Primary sources only -- the issuing body's own document, not a
   summary, blog, or secondary reference.
2. Separate what the source actually says from local policy and implementation
   assumptions. Thresholds chosen for convenience are not guideline content and
   must be labelled as local policy.
3. Record a named physician's approval, with a date, per rule.
4. Only then flip the rule to active.

Until step 3 is recorded, treat every rule here as draft.
